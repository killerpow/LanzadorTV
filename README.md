# Lanzador TV

Pantalla de inicio ligera y sin anuncios para Android TV / Google TV, organizada por secciones (Cine, Series, Música, Aplicaciones…).

## Uso con el mando
- **OK**: abrir la app.
- **Mantener OK** sobre una app: moverla a otra sección, crear una sección nueva, cambiar su orden o quitarla.
- **⚙ Secciones** (arriba a la derecha): subir, bajar, renombrar o borrar secciones.

## Obtener el APK
Cada vez que se suben cambios, GitHub Actions compila la app y publica `LanzadorTV.apk` en **Releases**.
