# Lanzador TV

Pantalla de inicio ligera y sin anuncios para Android TV / Google TV, organizada por secciones (Cine, Series, Música, Aplicaciones…).

## Uso con el mando
- **OK**: abrir la app.
- **Mantener OK** sobre una app: moverla a otra sección, crear una sección nueva, cambiar su orden o quitarla.
- **⚙ Ajustes** (arriba a la derecha): secciones, fondo de pantalla, modo «sustituir inicio» y ajustes del televisor.
- **Cambiar imagen…** (mantener OK sobre una app): usa una foto tuya como imagen de esa app.

## Que arranque siempre al encender la TV
Ajustes → Sustituir inicio → activa «Lanzador TV (sustituir inicio)» en Accesibilidad.
Si usabas Projectivy, desactiva su opción equivalente para que no se peleen.

## Obtener el APK
Cada vez que se suben cambios, GitHub Actions compila la app y publica `LanzadorTV.apk` en **Releases**.
